Current limitations are explicit in configuration.md. The bounded JSONPath subset
is not unrestricted RFC 9535; the gateway uses the actual JsonPath.Net parser and
evaluation for supported selectors, including slices, bounded unions, up to two recursive descents and up to two outer filters. Case-distinct and repeated cookie names are exercised through the public middleware. Relative and root wildcard/slice existence and bounded `count()`/`value()` have focused middleware and real-upstream regression cases, including repeated-root budget rejection. Bounded predicate unions preserve duplicate nodes and have a separate real-upstream budget oracle. One outer descent combined with a filter has positive/negative middleware cases and a separate real-upstream overlapping-traversal budget oracle. Bounded predicate descent is exercised for existence, count/value and combined outer descent with a separate real-upstream work limit. One nested relative filter is supported, including outer unions and a second outer filter, with middleware cases and a real-upstream budget oracle. Length comparisons use a per-path selector with scalar-correct Unicode counting, collection lengths, scalar literals, singular comparison queries on either side and length-to-length comparisons, Nothing semantics, and the same precharges; match/search use a bounded I-Regexp subset (including grouping, alternation, bounded explicit repetitions and positive/negative Unicode scalar literal classes and general-category escapes), private selectors, scalar-correct dot, compile-time scalar-literal input evaluation, non-string false semantics and shared regex budget (GatewayTests.RfcSelectorsSupportBoundedPathsAndFilters, ForwardingTests.RegexFilterIsScalarCorrectAndBudgetedWithoutGlobalRegistration). Outer compound length/regex predicates combine private and pinned library predicates with short-circuit semantics and precharged regex visits. Single nested relative existence filters with private functions have public middleware and real-upstream scope, no-call, body preservation, registry identity and work-limit tests (ForwardingTests.NestedPrivateFilterUsesCandidateScopeAndFailsClosed). Private nested relative filters inside count/value on either side of a comparison with a literal, singular relative query, scalar-correct length of a singular relative query or literal, or bounded relative count/value call use the same middleware and real-upstream oracles, including Nothing versus null, unlike-type count literals, typed and structural comparison, scalar ordering and fail-closed budget checks. Relative value conversions within private length/match/search predicates and on the length side of nested count/value comparisons retain quadratic work and regex visit charges, with positive, negative, startup rejection and real-upstream budget tests. One bounded numeric-returning count/length function argument is also supported for length and both regex arguments, with typed Nothing/false results, startup rejection of out-of-profile arguments and real-upstream precharge controls. Inner root references in a single nested relative filter (ordinary existence/comparison or private functions) preserve document scope and the quadratic budget, with public middleware and real-upstream positive, negative and no-call budget cases. Root-scoped ordinary nested predicates use the same isolated compiled selector; startup rejects root-driven enclosing queries, predicate unions and descent. The bounded existence result consumes the complete nodelist so later evaluation failures cannot be hidden by an earlier match. Root-driven enclosing queries, bare non-singular and other unsupported function-valued comparison operands for private nested functions, unsupported I-Regexp constructs, deeper nesting and combinations exceeding documented traversal/union limits remain unsupported. The regex timeout oracles use an actual engine timeout at the distinct request and
configuration classification boundaries. A constant regex timeout during rule
compilation is an invalid candidate configuration, not a request failure; the
reload loop retains the last good snapshot. Production rules use nonbacktracking
patterns and bounded evaluation. The DNS oracle uses a local
TCP listener to detect forbidden connection attempts; external DNS rebinding
and deployment network policy are not exercised against real systems.
